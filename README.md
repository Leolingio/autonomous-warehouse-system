---

## 📌 Project Overview

This project simulates an autonomous multi-robot fleet operating in a dynamic warehouse environment. Built on **ROS2** and **Gazebo**, it demonstrates modern robotics concepts including central fleet coordination, real-time collision avoidance and automated task distribution.

> [!NOTE]
> **Project Status:** Active Development ⏳  
> Core architectural components and simulation environments are currently being implemented.
